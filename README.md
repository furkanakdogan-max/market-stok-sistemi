# Market Stok Sistemi

## Proje Hakkında
Bu proje, marketlerde bulunan ürünlerin stok durumunu takip etmek amacıyla geliştirilmiştir. Kullanıcı sistem üzerinden ürün ekleme, silme, güncelleme ve stok listeleme işlemlerini yapabilmektedir.

## Kullanılan Yapılar
Projede Python programlama dili kullanılmıştır. Kod yapısı Nesne Tabanlı Programlama (OOP) mantığına uygun şekilde hazırlanmıştır. Proje modüler bir yapıda geliştirilmiş ve dosyalar görevlerine göre ayrılmıştır.

## Proje Özellikleri
- Ürün ekleme
- Ürün silme
- Stok güncelleme
- Ürün listeleme
- Basit menü sistemi

## Dosyalar
- main.py → Programın çalıştığı ana dosya
- urun.py → Ürün sınıfı işlemleri
- stok.py → Stok yönetimi işlemleri
- sale.py → Ürün satışı işlemleri

## Çalıştırma
Projeyi çalıştırmak için terminal üzerinden aşağıdaki komut kullanılabilir:

```bash
python main.py
```
